# Estudos em C

Repositório dedicado aos meus estudos da linguagem C, com foco em lógica de programação. Aqui eu vou guardando pequenos exercícios praticados durante o aprendizado, evoluindo de conceitos básicos até estruturas mais avançadas.

## Objetivo

Fixar e praticar lógica de programação usando C como linguagem base, indo do básico ao intermediário:
- Variáveis e condicionais
- Estruturas de repetição (`for`, `while`, `do while`)
- Vetores
- Strings
- Struct
- Funções

## Organização

Cada arquivo `.c` representa um exercício isolado e funcional, com um comentário no topo explicando o objetivo dele.

| Arquivo | Conceito praticado |
|---|---|
| `01_vetor_maior_menor.c` | Vetor: encontrar maior, menor, soma e média de uma lista de números |
| `02_vetor_produtos_faixa.c` | Vetor: contagem condicional por faixa de valores (preços/produtos) |
| `03_vetor_faixas_notas.c` | Vetor + `if/else if` encadeado: classificar notas por faixa de desempenho |
| `04_funcao_soma_mult.c` | Função: parâmetros e retorno (`return`) com cálculos simples |
| `05_funcao_void_media.c` | Função `void`: calcular e exibir resultado dentro da própria função |

*(a tabela vai sendo atualizada conforme novos exercícios entram no repositório)*

## Sobre o aprendizado

Esses exercícios fazem parte do caminho de estudo antes de um projeto maior: um **Sistema de Gerenciamento de Notas de Alunos**, que vai unir todos esses conceitos (vetores, struct, funções e menu interativo) em um único programa.
